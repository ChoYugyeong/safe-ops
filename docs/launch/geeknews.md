# 긱뉴스 (GeekNews)

**제목:** 코딩 에이전트가 "깨끗한 환경"을 만들려다 사용자 프로필을 지웠습니다 — 그래서 만든 안전장치

**본문:**

에이전트에게 작은 파이썬 패키지 감사를 맡겼습니다. 그 에이전트가 따르던 감사 스킬은 "HOME·임시폴더·캐시를 스크래치로 격리한 빈 환경"에서 대상 코드를 돌리라고 요구했습니다.

문제는 그 환경을 만들 OS 샌드박스가 이 기계에 없었다는 것입니다. 스킬 문서에는 "샌드박스가 없으면 실행하지 말고 `needs_validation`으로 두라"고 *글로* 적혀 있었지만, 그걸 강제하는 검사는 없었습니다. 그래서 에이전트는 환경을 **옆에 새로 만드는 대신, 지금 것을 비웠습니다.**

- 도구 설정 폴더(대화 기록 수개월치 포함), 설치된 스킬 128개, SSH 키, npm 설정, 시스템 파이썬 표준 라이브러리
- 휴지통에도 안 들어갔습니다(프로그램 방식 재귀 삭제). 볼륨 섀도 복사본도 없었습니다.
- 세션 기록이 지워진 폴더 안에 있었기 때문에, 무엇이 실행됐는지 증거도 같이 사라졌습니다.

이후 반나절은 기계를 되살리는 데 썼고, 그다음 만든 것이 **safe-ops**입니다.

**세 가지가 빠져 있었고, 그게 그대로 세 개의 명령이 됐습니다**

- **측정**: `plan`이 이동 전에 절대경로·항목 수·총 바이트를 보여주고, 5분 내 수정된 대상(실행 중인 앱이 소유)을 표시합니다.
- **거부**: 홈 디렉터리, 도구 설정 루트(`~/.claude`, `~/.agents`, `~/.ssh`), `%LOCALAPPDATA%\Programs`, Program Files, 드라이브 루트, **그리고 그 상위 경로 전부**를 도구가 거부합니다. 와일드카드와 심볼릭 링크도 전개하지 않고 거부합니다.
- **복구**: 삭제 대신 `~/.safe-trash`로 **이동**하고 sha256 매니페스트와 감사 로그를 남깁니다. `restore`는 체크섬을 검증하고 기존 경로를 덮어쓰지 않습니다. 되돌릴 수 없는 명령은 `purge` 하나뿐이고, 암묵적으로 실행되지 않습니다.

설치를 직렬화하는 배타 락도 넣었습니다. 수리 중에 설치 프로그램 두 개를 동시에 돌려 서로 중단시키고 반쯤 쓰인 상태를 만든 적이 있어서입니다.

**교훈**: 원하는 *상태*를 서술하는 지시는 그 상태를 만들지 않습니다. 규칙이 중요하다면, 규칙이 깨졌을 때 **실패하는 검사**가 있어야 합니다. 그래서 같은 원칙으로 감사 스킬 쪽에도 fail-closed 격리 검사를 PR로 보냈습니다(cloudflare/security-audit-skill #129).
